TTS — Text to Speech

Microphone & Voice

Always Listening is fixed in Saeed and remains enabled. VAD handles turn detection automatically.

Permissions

Default: Full Access

Saeed is allowed to perform normal requested operations without routine approval. Use the controls below only if you want to restrict him.

Operation categories

Choose what Saeed should do with each category. Allow keeps normal full access; Ask Always shows Allow/Deny; Deny blocks the category.

Critical operations

Shutdown/restart/logoff, protected system changes, financial actions, software removal/installation and other irreversible operations remain protected by an Allow/Deny prompt when the critical option is enabled.

API & Character

API keys for LLM / STT / TTS / Realtime are stored locally using Electron safeStorage. Realtime remains Always Listening and is not disabled by this screen.
